## Özellikler

| | |
|---|---|
| 🔐 **Google ile giriş** | Tek dokunuşla kayıt, kullanıcı adı / biyografi / profil fotoğrafı |
| 🔢 **6 haneli PIN kilidi** | Unutulursa hesap silinir, veriler sıfırlanır |
| 💬 **DM ve Kulüpler** | Herkese açık ya da gizli (süreli davet bağlantılı) kulüpler |
| 🧷 **Özel çıkartmalar** | 32 özel Anonymous çıkartması |
| 🏅 **Rozetler** | Yöneticinin verdiği özel rozetler |
| 🖼️ **Tek seferlik görsel** | Bir kez açılır, ekran görüntüsü engellenir |
| 🗑️ **Akıllı silme** | İlk 5 dakika herkesten sil, sonra sadece kendinden |
| ⏳ **Otomatik temizlik** | Mesajlar en fazla 10 gün, indirilmeyen dosyalar 15 dk |
| 🔔 **Bildirimden yanıt** | WhatsApp gibi bildirim panelinden cevapla, `@etiket` bildirimi |
| 👥 **Takip ve engelleme** | Engellenen kişi sana "Anonymous" olarak görünür |
| ⚖️ **Yargıç sistemi** | Şikayetler yetkili kişilere Yargıç'tan iletilir |
| 🛡️ **Yetki hiyerarşisi** | Aç/kapa yetki listesi, Administrator, etiketler |
| 🌍 **4 dil** | Türkçe (varsayılan), English, Deutsch, Русский |
| 🌗 **2 tema** | Koyu ve açık |

## Kurulum

1. [Releases](https://github.com/ThT0AltayHR/anonmessage/releases/latest) sayfasından **`Anonymous.apk`** dosyasını indir.
2. Telefonda *Bilinmeyen kaynaklardan yüklemeye izin ver* seçeneğini aç.
3. APK'yı aç ve kur.
